# 地推登記

活動現場快速收集 email 的小工具。單一網頁、不需安裝；資料先存在使用者自己的瀏覽器（localStorage），設定雲端同步後，有網路時會自動上傳到 Google 試算表。

## 使用方式

- **電腦**：直接點兩下 `index.html`，或開啟 GitHub Pages 網址。
- **平板 / 手機**：用瀏覽器開啟 GitHub Pages 網址 →「加入主畫面」（iPad：Safari 分享按鈕 → 加入主畫面；Android：Chrome 選單 → 安裝應用程式 / 加到主畫面）。之後從主畫面圖示開啟，沒網路也能用。

## 雲端同步到 Google 試算表

每場活動（日期 + 地點）一張工作表，一個 email 一列，並記錄登記時間與登記裝置。
不同裝置只要日期和地點打得一樣，就會合併到同一張工作表。

**管理者設定一次：**
1. 打開試算表 → 擴充功能 → Apps Script
2. 刪掉原本內容，貼上 [`google-apps-script/Code.gs`](google-apps-script/Code.gs) 全部內容 → 儲存
3. 部署 → 新增部署作業 → 類型「網頁應用程式」，執行身分「我」、誰可以存取「所有人」→ 部署 → 授權 → 複製網址

**每台裝置：** 首頁最下方「☁ 雲端同步」→ 貼上網址、輸入裝置名稱 → 儲存並測試連線。

同步網址只存在各台裝置上，沒有寫進程式碼（這個 repo 是公開的）。請只傳給工作人員。

## 注意

- 同一台裝置可以同時有多場活動，也可以同時開多個分頁/視窗，資料不會互相覆蓋。
- 資料存在「該裝置的該瀏覽器」中；清除瀏覽器資料會一併刪除。尚未同步的資料請先「匯出 TXT」備份。
- iPad 上「主畫面 App」和「Safari 分頁」的資料與設定是分開的，請固定從同一個地方開啟。
- 同步是單向的（裝置 → 試算表）：直接在試算表裡改或刪資料，不會影響裝置上的資料。
- 修改 `index.html` 後，請把 `sw.js` 裡的 `CACHE` 版本號加 1，平板才會更新到新版。
