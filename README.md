# 地推登記

活動現場快速收集 email 的小工具。單一網頁、不需安裝，資料只存在使用者自己的瀏覽器（localStorage），不會上傳到任何伺服器。

## 使用方式

- **電腦**：直接點兩下 `index.html`，或開啟 GitHub Pages 網址。
- **平板 / 手機**：用瀏覽器開啟 GitHub Pages 網址 →「加入主畫面」（iPad：Safari 分享按鈕 → 加入主畫面；Android：Chrome 選單 → 安裝應用程式 / 加到主畫面）。之後從主畫面圖示開啟，沒網路也能用。

## 注意

- 資料存在「該裝置的該瀏覽器」中，不同裝置不會同步；清除瀏覽器資料會一併刪除。每場活動結束請先「匯出 TXT」備份。
- iPad 上「主畫面 App」和「Safari 分頁」的資料是分開的，請固定從同一個地方開啟。
- 修改 `index.html` 後，請把 `sw.js` 裡的 `CACHE` 版本號加 1，平板才會更新到新版。
